## Critical Anti-Patterns

Each of these was discovered through an actual failure in the last session, not
predicted. All are fixed and documented in `CLAUDE.md`; they are listed here so a
resuming agent does not reintroduce them.

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Claiming animation is verified | The Browser pane is collapsed, so `document.hidden` is true and rAF delivers **0 frames/sec** (measured). Live motion cannot be observed from the agent side. | blocking | Never state the Zen animation "works" from inside this environment. Verify wiring indirectly (unit tests + computed transforms) and say plainly that live motion needs a human at a real browser window. |
| Unregistered custom properties | `transition: --sky-1 10s` is silently inert unless the property is declared with `@property`. Every phase change was hard-cutting. | advisory | All palette variables are registered at the top of `src/styles/zen.css`. Any new animated custom property must be registered there too. |
| Percentage translate | `translateY(100%)` resolves against the **element's own** box, not its parent — a 2px snowflake travelled 2px. | advisory | Snow and rain use full-height carrier columns with the visible dot/streak as a child. Keep that structure for anything that must cross the window. |
| Theme applied after paint | With no `data-theme` at load, a dark-preferring browser starts on the night palette and drifts to light over the transition duration. | advisory | An inline script in `index.html` reads `settings.theme` and sets `data-theme` before first paint. Do not remove it. |
| Blobs in IndexedDB | Blobs do not survive structured-clone in jsdom, and historically not in Safari. | advisory | `lib/storage/photos.ts` stores `{ type, bytes: ArrayBuffer }` and rebuilds the Blob on read. |
| `erasableSyntaxOnly` | TS 6 rejects constructor parameter properties (`constructor(private x: T)`). | advisory | Assign in the constructor body. |

<decisions_made>
- **Paper only** — no text editor anywhere, ever. This constraint shapes everything else.
- **Hand-authored prompts, never generated.** Armaan explicitly rejected live AI
  generation, wanting prompts that teach rather than fill.
- **Depth withheld until review** so it cannot contaminate the writing.
- **Three lanes, three rubrics** — a personal statement and an argument essay are
  different crafts.
- **Only the written prompt is consumed**; passed-over prompts return to the pool.
- **Weekly chain, not a daily streak** — a snapped streak after a good run demoralises.
- **Weather in Settings, scenery automatic** — Armaan's call on weather; scenery left
  to surprise, to keep Settings uncluttered.
- **Photos as bytes + mime**, not Blobs.
- **Pure modules for anything that could be wrong**, so correctness never depends on
  watching the screen — which proved essential.
</decisions_made>
